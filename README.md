# Book-Alchemy

A Flask web app for managing a personal book and author library. Add new books, view details, rate your reads, and get smart next-book recommendations powered by AI.

## Features

- **Add Books & Authors:** Easily add new titles or authors with key details.
- **Book Listing & Search:** Browse and search your library by title or author.
- **Ratings:** Optionally track your rating (out of 10) for each book.
- **Delete:** Remove books or authors in a click.
- **AI Recommendation:** Get a suggestion for what to read next, generated by AI based on your reading history.
- **SQLite Storage:** Persistent local database; simple setup via SQLAlchemy.
- **Full Web Interface:** Browse details, add new books/authors, and interact with your collection in your browser.

## Getting Started

1. **Clone this project:**
```bash
git clone https://github.com/Miami05/Book-Alchemy.git
```
```bash
cd Book-Alchemy
```

2. **Install requirements:**
```bash
pip install flask flask_sqlalchemy python-dotenv openai
```

3. **Set your environment variable (for AI recs):**
- Add your Groq/OpenAI API key in a `.env` file:
  ```
  GROQ_API_KEY=your_api_key_here
  ```

4. **Start the app:**
- Visit `http://localhost:5002` in your browser!

## Usage

- **Home:** View and search all books.
- **Details:** Click a book or author name for more info.
- **Add:** Use forms to add new books or authors.
- **Recommend:** Get personalized AI suggestions for your next read.

## Customization

- Extend models with more fields (genre, notes, etc.)
- Tweak templates for new looks or UX.
- Switch database to Postgres, etc., for deployment.
